`yes` means the connector implements the interface and declares the capability (the conformance kit checks that the two agree). `-` means it does not. The `remote` connector forwards every call to an HTTP service; that service decides its capabilities (`GET {base_url}/info`), so they are shown as `per service`.

- **Refunds**: `Refunder`: refund a payment, fetch a refund.
- **Disputes: read**: `DisputeReader`: list and fetch disputes (chargebacks).
- **Disputes: respond**: `DisputeResponder`: accept a dispute or submit evidence from the dashboard.
- **List (reconciliation)**: `Lister`: list payments and refunds, so the daily reconciliation can compare them.
- **Settlements**: `Settler`: list settlements (payouts).
- **Cancel checkout**: `Canceler`: cancel an open checkout at the provider.
- **Provider-managed subscriptions**: `SubscriptionManager`: the provider bills and retries recurring payments.
- **Mandates (merchant-triggered)**: `MandateManager`: Paymux debits a mandate (UPI AutoPay, card, e-mandate) on each renewal.
- **Connect (OAuth)**: `OAuthConnector`: the dashboard's Connect button authorises the account with the provider, so no grant code is pasted by hand.
